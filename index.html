Les serveurs / DevOps

Connaître le fonctionnement des serveurs est indispensable pour comprendre le fonctionnement des applications. Retrouvez ici toutes les ressources pour maîtriser les serveurs, Docker et l'intégration continue.

🧭 Par où commencer ?

Conseil : Si vous débutez, suivez les TP dans l'ordre : d'abord le serveur, puis Docker, et enfin l'intégration continue.
